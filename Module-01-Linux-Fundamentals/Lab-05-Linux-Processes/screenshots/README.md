## Redaction Requirements

Before committing screenshots:

- Crop to the relevant command and output.
- Redact passwords, API keys, access tokens, cookies, and session values.
- Redact public home IP addresses.
- Redact unrelated usernames and process command lines.
- Redact sensitive internal paths and proprietary service names.
- Hide unrelated desktop notifications and browser content.
- Do not include malware, untrusted binaries, or untrusted scripts.
